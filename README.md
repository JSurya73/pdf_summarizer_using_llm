# PDF Q&A Chatbot using RAG

A Retrieval-Augmented Generation (RAG) application that lets you upload a PDF and ask questions about its content in a chat interface. Answers are generated by Llama 3.1 and grounded only in the retrieved parts of the document.

## Features

- Upload any PDF and chat with it
- Answers grounded in the document, with page references for traceability
- Responds "I don't know" when the answer is not in the document
- Two decoupled Flask services: one for vector indexing, one for LLM inference
- Simple web chat UI (HTML, CSS, JavaScript)

## Tech Stack

| Component | Technology |
|---|---|
| Orchestration | LangChain |
| PDF loading | PyPDFLoader |
| Chunking | RecursiveCharacterTextSplitter (1000 chars, 150 overlap) |
| Embeddings | HuggingFace `sentence-transformers/all-mpnet-base-v2` |
| Vector store | FAISS |
| LLM | Llama 3.1 8B Instant via Groq |
| Backend | Flask, Flask-CORS |
| Frontend | HTML, CSS, JavaScript |

## How It Works

1. **Upload:** the PDF is sent to the vector DB service (`/upload`, port 2000).
2. **Index:** the PDF is split into chunks, embedded, and stored in a FAISS index, which is returned to the browser.
3. **Ask:** the question and the index are sent to the LLM service (`/llmcall`, port 2001).
4. **Retrieve and answer:** the most relevant chunks are retrieved and passed to Llama 3.1 with a strict prompt, and the answer is returned to the chat UI.

## Project Structure

## Setup

**1. Clone the repository and install dependencies**

```bash
git clone <your-repo-url>
cd pdf_summarizer_using_llm
pip install -e .
pip install flask flask-cors langchain langchain-community langchain-huggingface \
            langchain-groq langchain-text-splitters faiss-cpu pypdf \
            sentence-transformers colorama
```

**2. Set your Groq API key**

Get a free key from the [Groq Console](https://console.groq.com) and export it:

```bash
export GROQ_API_KEY="your_api_key_here"      # Linux / macOS
set GROQ_API_KEY=your_api_key_here           # Windows (cmd)
```

Never commit your real API key to the repository.

**3. Start both services (in two terminals)**

```bash
python apis/vectorDB_api.py    # http://127.0.0.1:2000
python apis/llm_call.py        # http://127.0.0.1:2001
```

**4. Open the app**

Go to `http://127.0.0.1:2000`, upload a PDF, and start asking questions.

## Limitations

- The FAISS index is passed between the browser and the server on each request, so very large PDFs may be slow.
- Uses `allow_dangerous_deserialization` when loading the index, so only use it with indexes created by your own service.
- Designed for single-document question answering.
